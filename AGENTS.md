Toolbelt is Tom's public monorepo of personal agent tooling: Pi packages (`claude-plugin-loader/`, `pi-{extensions-local,offshoot,recap,subagents,todo}/`) and small utilities (`agentlog/`, `iterm-snapshot/`, `agent-browser-plugin-allow-loopback/`). Tom's BB plugins live in `tomdale/bb-plugins` (`~/Code/Repos/bb-plugins/main`) and `tomdale/bb-plugin-workstreams` (`~/Code/Repos/bb-plugin-workstreams/main`), each with its own AGENTS.md. Each package owns its manifest, lockfile, and scripts; install and run them from the package directory. `pi-recap/`, `pi-subagents/`, and `pi-todo/` are forks of third-party packages and keep their upstream LICENSE; `pi-recap/UPSTREAM.md` and `pi-subagents/UPSTREAM.md` record source, base commit, and local changes, so update them with any change to those packages.

The canonical checkout `~/Code/Repos/toolbelt/main` is live: Pi loads the Pi packages from `main/` through `~/.pi/agent/settings.json`, whose source is dotfiles `home/dot_pi/agent/settings.json` (adding, renaming, or removing a Pi package changes that file too; see the `agent-config` skill). Change code only in your own Workforest task and follow the `personal-repo-lifecycle` skill through push and cleanup.

Pi package checks: the package's declared scripts, then `pi -p --no-session -ne -e <task>/<package> --model vercel-ai-gateway/openai/gpt-6-luna-fast 'Reply with exactly: ok'`, which loads only the task copy and must print `ok` with no "Failed to load extension" warning. Pi picks up main in a new session or after `/reload`. `pi-todo/`'s `test` script runs only inside the upstream rpiv-mono workspace, whose harness (`test/setup.ts`, `@juicesharp/rpiv-test-utils`) it imports.

Package-type guides: `.agents/skills/{pi-plugins,claude-plugins,codex-plugins}`.
